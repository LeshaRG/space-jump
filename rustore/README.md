# Space Jump для Android (RuStore)

Android-версия игры для RuStore. Код игры общий с версией для Яндекс Игр (корень
репозитория). В этой папке лежит только то, что отличается на Android: обёртка
[Capacitor](https://capacitorjs.com), реклама Яндекса для приложений, кнопка
«Назад», личные рекорды, политика конфиденциальности и материалы для карточки.
Версию для Яндекса эта папка не трогает: `build.ps1` в корне её не берёт.

## Чем отличается от версии для Яндекс Игр

| | Яндекс Игры | Android (RuStore) |
|---|---|---|
| Платформа | `src/ysdk.js` (SDK Яндекс Игр) | `rustore/src/platform.js` — подставляется вместо `ysdk.js` при сборке |
| Реклама | SDK Яндекс Игр | Yandex Mobile Ads SDK 8.5 (РСЯ для приложений), нативный плагин `YandexAdsPlugin` |
| Вход, облако | аккаунт Яндекса, `player.setData` | нет: прогресс хранится в приложении |
| «Рекорды» | лидерборд `score` | лучшие забеги на этом телефоне (топ-10 с датой и высотой) |
| Тестовая кнопка «+10 000» | на localhost и GitHub Pages | нет никогда (`rustore/src/testing.js`) |
| «Назад» Android | — | забег → пауза, пауза → продолжить, окна → назад, конец забега → меню, меню → свернуть |
| Прочее | — | вибрация на ударах и приземлениях (по системной настройке), экран не гаснет в забеге, весь экран без панелей, только портрет |

Игра работает без интернета: всё лежит внутри APK. Интернет нужен только рекламе.

## Что где

```
rustore/
  app.config.json        пакет, версия, рекламные блоки — всё, что меняется от версии к версии
  build.ps1              сборка подписанного APK одной командой
  capacitor.config.json  настройки Capacitor
  src/platform.js        платформа Android (вместо src/ysdk.js)
  src/testing.js         без тестовых кнопок (вместо src/testing.js)
  src/android.css        стили Android-версии (ссылка на политику, скрытие кнопок рекламы)
  privacy/index.html     политика конфиденциальности (в игре и на GitHub Pages)
  scripts/build-web.mjs  веб-часть: игра → www/ с подменой модулей
  scripts/make_icons.py  иконки лаунчера из арта игры
  scripts/make_store.py  тексты карточки RuStore с проверкой лимитов, скриншоты
  android/               Android-проект (MainActivity, плагины YandexAds и GameHost)
  store/                 карточка RuStore: texts.md, icon.png, screenshots/
  keystore/              КЛЮЧ ПОДПИСИ (в git не попадает)
  dist/                  готовые APK (в git не попадают)
```

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File rustore\build.ps1
```

Результат — `rustore/dist/space-jump-<версия>.apk`, подписанный ключом из
`rustore/keystore/`. Отладочная сборка (`-Debug`) показывает тестовую рекламу
Яндекса, если свои блоки ещё не указаны.

Нужны Node.js 22+, JDK 21 и Android SDK 36. Сейчас они лежат в `E:\Android`
(`jdk-21`, `sdk`, кеш Gradle — `gradle-home`), скрипт находит их сам. На другом
компьютере подойдёт Android Studio: скрипт возьмёт JDK и SDK из её стандартных
путей.

Проверить веб-часть без телефона: запустить `start.bat` в корне и открыть
`http://localhost:5174/rustore/www/index.html`. С `?fakeads` в конце адреса
реклама имитируется, и видны кнопки «продолжить» и «×2».

## Проверка на телефоне

1. Скопируйте APK из `rustore/dist/` на телефон и откройте его. Android попросит
   разрешить установку из этого источника.
2. Или через USB с включённой отладкой:
   `E:\Android\sdk\platform-tools\adb.exe install -r rustore\dist\space-jump-1.0.0.apk`

Отладочная сборка (`space-jump-<версия>-debug.apk`) ставится рядом с настоящей:
у неё свой пакет `ru.lesharg.spacejump.debug`, название «Space Jump тест» и
тестовая реклама Яндекса. Так можно проверить рекламу до того, как появятся свои
блоки РСЯ.

## Ключ подписи — сделайте копию

`rustore/keystore/spacejump-release.jks` и `keystore.properties` (в нём пароль) —
это ключ, которым подписана игра. RuStore принимает обновления только с тем же
ключом. **Потеряете ключ — выпустить обновление будет нельзя**, только новую игру
с нуля. Скопируйте папку `keystore` в облако или на флешку. В git она не попадает,
и выкладывать её нельзя: репозиторий публичный.

## Реклама (РСЯ)

Пока в `app.config.json` блоки пустые, в релизной сборке реклама выключена:
SDK не запускается, кнопки «за рекламу» скрыты, игра полностью рабочая.

Как включить:

1. [partner.yandex.ru](https://partner.yandex.ru) → «Мобильные приложения» →
   добавить приложение из RuStore. Доступ подтверждается почтой или сайтом
   разработчика из карточки RuStore, либо файлом `app-ads.txt` (ниже).
2. Создайте два блока: **Полноэкранный** (Interstitial) и **С вознаграждением**
   (Rewarded). Их идентификаторы имеют вид `R-M-1234567-1`.
3. Впишите их в `app.config.json`:
   ```json
   "ads": { "interstitial": "R-M-…-1", "rewarded": "R-M-…-2", "ageRestricted": true }
   ```
4. Увеличьте `versionCode` (например, до 2), поменяйте `versionName`, соберите и
   загрузите обновление в RuStore.

**app-ads.txt.** РСЯ попросит положить строку вида `yandex.com, <ваш ID>, DIRECT`
в файл `app-ads.txt` в корне сайта разработчика, указанного в карточке RuStore.
Для GitHub Pages корень — `https://lesharg.github.io/`, это отдельный репозиторий
`LeshaRG.github.io` с файлом `app-ads.txt` в корне. Сайт в карточке RuStore тогда —
`https://lesharg.github.io`.

**Возраст и персонализация.** `ageRestricted: true` — реклама без персонализации.
Это обязательно при рейтинге 0+ и 6+ (п. 9.7 правил RuStore). Если поставите в
карточке 12+, можно указать `false`: доход выше, но тогда поправьте раздел
«Реклама» в политике конфиденциальности.

Частоту показа задаёт общий `src/config.js` (`ADS`): полноэкранная — на каждом
втором конце забега и не чаще раза в минуту, видео за награду — только по кнопке.

## Публикация в RuStore

1. [RuStore Консоль](https://console.rustore.ru) → вход через VK ID → тип аккаунта
   **«Физическое лицо»**. Для бесплатной игры с рекламой ИП не нужен.
2. Политика конфиденциальности — `privacy/index.html` (почта для связи:
   revork.coconut@gmail.com). После пуша в GitHub она открывается по адресу
   `https://lesharg.github.io/space-jump/rustore/privacy/` — эту ссылку укажите в
   карточке. Поменяли текст — пересоберите APK (политика есть и внутри игры) и запушьте.
3. «Приложения» → «Создать приложение» → загрузите APK из `rustore/dist/`.
4. Карточка: тексты, категория, рейтинг и ссылки — в [store/texts.md](store/texts.md);
   иконка `store/icon.png`; скриншоты `store/screenshots/`. Видео — только ссылкой на
   VK Видео (можно загрузить `../store/ru/video_vertical.mp4`).
5. Отправьте на модерацию: до 72 часов. При отказе можно подать одну апелляцию на
   support@rustore.ru.

## Обновление

Меняете игру как обычно, в корне репозитория. Для RuStore поднимите `versionCode`
(на 1) и `versionName` в `app.config.json`, запустите `build.ps1` и загрузите APK
как новую версию. `versionCode` должен расти с каждой загрузкой.

## Как устроено

- `scripts/build-web.mjs` собирает игру esbuild'ом из корня и при этом направляет
  импорты `./ysdk.js` и `./testing.js` в эту папку. Если подмена не сработала или в
  бандле осталось обращение к SDK Яндекс Игр, сборка падает.
- `src/platform.js` дополняет меню и рекорды через DOM: ссылка на политику, подпись
  «на этом телефоне». Он опирается на классы `.screen.menu`, `.screen.leaders`,
  `.lb-rank`, `.lb-table`, `.btn.ad`, `.revive`, `.bcard.coins` и на кнопки
  `data-act="back|close|resume|menu"` из `src/ui/screens.js`. Если их переименовать,
  проверьте этот файл.
- Рекорды записываются через обёртку над `GameState.recordScore`. Забег, продолженный
  за рекламу, обновляет свою запись, а не добавляет вторую.
- `android/app/build.gradle` читает пакет, версию и рекламные блоки из
  `app.config.json` и подписывает релиз ключом из `keystore/`.
- `MainActivity` прячет панели Android и отодвигает игру от выреза камеры.
  `YandexAdsPlugin` заранее загружает рекламу и отдаёт игре результат показа.
  `GameHostPlugin` отвечает за вибрацию, «не гасить экран» и открытие ссылок.

## Онлайн-рекорды

В RuStore своих таблиц рекордов нет: GameCenter SDK в закрытой бете, рекордов в нём
нет, и он работает только вместе с платёжным SDK для ИП и юрлиц. Общую таблицу можно
сделать на своём сервере, например на Яндекс Облаке. Тогда `getEntries` и
`submitScore` в `platform.js` будут ходить туда.
