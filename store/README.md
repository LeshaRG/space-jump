## Как это сделано

**Скриншоты — настоящий забег.** Игра запускается в Chrome без окна и
снимается через протокол DevTools вместе с HTML-интерфейсом (счёт, жар,
монеты, бустеры), как на экране телефона, в 1080×1920. Играет бот
(`tools/bot.js`) — настоящей рогаткой: зажимает, оттягивает и отпускает,
поэтому в кадре видны вектор прицела и натяжение. В каждом кадре свой
скин: классика, Марс, байкер, ромашки, демон.

1. рогатка и вектор прицела, жар ×2;
2. жар ×3 (голубое пламя) и «монеты ×2»;
3. джетпак: счётчик очков в полёте;
4. чёрная дыра и предупреждение о метеорите;
5. премиум-скин и выбор платформы для телепорта.

**Скриншоты для компьютера.** Игра портретная: в окне 16:9 поле занимает
треть ширины. Поэтому по центру стоит настоящий кадр в полную высоту, а
по бокам — та же сцена (размытая), персонаж, логотип и подписи. Правила это
разрешают: пустое место можно заполнить игровыми локациями, персонажами и
поясняющим текстом (п. 5.1.1.2), запрещены только заливка, градиенты и
чужие материалы.

**Иконка и обложки собраны из арта игры** (герой, скины, платформа, космос в
стиле фона игры): скриншоты в иконке и обложке запрещены (п. 5.6).

**Видео** — запись того же забега с ботом (~100 кадров/с, сведено к 30):
прыжки, рикошет, джетпак, жар ×3, метеорит, телепорт, чёрная дыра. В
горизонтальном по бокам — размытая копия того же кадра, без посторонней
графики (п. 5.1.1.3). Рекламные — нарезка лучших моментов с подписями,
переходами, парадом скинов и финальной карточкой. Звук — музыка игры.

## Как пересобрать

Нужны Node.js 22+, Chrome или Edge, Python (Pillow, numpy) и ffmpeg.

```bash
node store/tools/capture.mjs
```
```bash
node store/tools/record.mjs ru
```
```bash
node store/tools/record.mjs en
```
```bash
python store/tools/make_media.py
```
```bash
python store/tools/make_video.py
```

`capture.mjs` снимает скриншоты (сценарии — в начале файла), `record.mjs` —
забег для видео (падение героя — дубль переснимается сам), `make_media.py`
собирает иконки, обложки и скриншоты и проверяет размеры, `make_video.py` —
ролики. Сырые кадры лежат в `store/_raw/` и `store/_rec/` (сотни МБ) — в git
они не попадают. Готовые материалы в этой папке — около 110 МБ, почти всё —
видео.
